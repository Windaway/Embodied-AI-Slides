# 具身智能导论 · 课程讲义

本项目是一套实验室内部**具身智能（Embodied AI）科普教程初稿**——《具身智能导论：从三维感知到视觉-语言-动作大模型》课堂讲义，覆盖机器人本体、空间感知、抓取与操作、模仿学习与强化学习、世界模型、VLA 大模型、Sim-to-Real、人形全身控制与具身安全等主题。

本项目**使用大模型（LLM）工具建立**：讲义内容由大模型辅助整理与撰写，并经人工编排，后续会进行更新。
